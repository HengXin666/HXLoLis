# 项目代码质量全景契约

每次调用都产出或更新**目标项目自己的**全景文档: 优先采用既有文档目录与命名; 无约定时 docs/code-quality-landscape.md. 读 impl/landscape.md 获取内容和图的最小契约, 填真实路径和数据, 不把空白模板当交付物

产物: 仓库边界、当前有效检查、本地与 GitHub 文档/工作流两路、信号到检查点的 Mermaid 流程图、已知缺口、建议与不装项、证据路径、验证命令及测量日期. 仅限用户要求定点变更时可缩小分析面, 但仍记录该范围及与全景其余部分的未知边界

导览骨架来自 templates/skeletons/14-guide.md(相对 skill 根); 在它的章节上补完整 REF-1..31 裁决表、所处 A/B/C 层、PY-01..04 和宿主新增规则、实际验证与待确认项. 图要连到真实判据和检查点, 不能只画"本地→远程"抽象方框

过关: 图上每条实线有执行入口或配置证据, 未验证路径用虚线标记; 读者可沿图追溯到文件或运行结果. 首次文档用于盘点, 不能为了画满全景去虚构门禁; 随项目演进更新现况, 不生成一篇与实际检查脱节的静态方案
