# GitHub 协作文档

检查实际启用的 .github/PULL_REQUEST_TEMPLATE.md、.github/PULL_REQUEST_TEMPLATE/、.github/ISSUE_TEMPLATE/ 与 config.yml、CONTRIBUTING.md、CODEOWNERS、讨论或发布模板.

逐一回答: 是否存在、用户入口能否到达、哪些字段提供可审查证据、哪些只是未强制文字、与已有流程是否重复. Issue 模板与 PR 模板是协作输入, 不能宣称它们会令构建失败

只有发现反复缺少的评审信息或可重现的协作痛点才提议补模板; 根据项目已有问题类型设计字段. 验证路径与模板语法, 能访问托管端时验证入口和必需字段; 对于 CODEOWNERS 与审批规则要区分配置文件和托管端真正强制的规则
