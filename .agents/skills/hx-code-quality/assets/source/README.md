# 可抄起点: 一套已经跑起来的红线系统

这里放的是 weuinevolveweb 那套质量基建的**形状与参数**, 供 `code-quality-redlines` 落新仓时当起点。
语义与 `agent-harness-architect/assets/` 相同: **可改编的起点, 不是能原样倾倒的成品**。

抄什么、不抄什么, 一句话:

- **抄形状**  交付物有哪几件、每件管什么、门禁脚本必须满足哪些书写约定、探针怎么写。
- **抄参数名, 不抄参数值**  阈值 / 豁免名单 / lane 前缀 / 工具集合都换成本仓实测的结果。
  本仓的 31 条门禁是**一个**仓库付得起的答案, 不是标准答案。

> 原决定 (`.agents/notes/implemented/process/2026-10-02-code-quality-redlines-skill.md`) 曾明确否决
> "给模板"。2026-10-02 由用户翻案: 模板照样给, 但按"起点"而不是"终点"给  参数快照带日期与重算命令,
> 任何数字都必须在目标仓重新量一遍。**这条翻案是本文件存在的唯一理由。**

## 三档起步

不是三个套餐, 是三段**可独立验证、独立回滚**的增量  走完一档再决定要不要下一档。

**最小可用回路**(有意义的最小集; 少任何一件都会退化成"看起来有门禁")
1. `run.mjs`(注册表 + 入口 + 五机制)
2. 一条判据  选**成本最低、误报最少**的那条, 通常是"已有配置但从不执行"的类型检查/格式化
3. 一条探针(违规组 + 控制组), 判据脚本必须支持用环境变量把扫描根指到临时目录
4. 接线: `hook-lanes.mjs` + `hook-stop.mjs` + 一份 settings 的 Stop 注册
5. 指纹的**两组**都要(只做第一组 = 门禁被摘掉没人知道)

**标准档**
+ 棘轮基线(存量不清零) + 白名单双向校验 + 决策记录制度 + 事故规则表
+ pre-commit(只碰暂存文件、只做能自动修的事) + pre-push

**全量档**
+ CI 多 job + 路径分流 + e2e lane + 文档体量预算 + 契约快照 + `--dry-run`

## 抄前必答(≤5 问, 答不出就先别写脚本)

1. **这条红线拦的是哪一次真实发生过的失败?** 拿得出命令 / 文件 / 次数吗? 拿不出就标"预防性"。
2. **阈值是按本仓分布算的吗?** 本仓的 300 / 500 / 5 / 15 / 10 全是**本仓分布**的读数,
   换仓必须重算(p90 法见 `../references/gate-catalog.md`)。
3. **扫描根能被环境变量指到别处吗?** 不能就先改脚本  否则探针做不出来, 这条红线永远无法自证。
4. **`hook-lanes.mjs` 的前缀表覆盖了这个仓的所有顶层条目吗?** 谁在机器校验它?
   漏一类的症状是"改了东西但一条门禁都不跑", 运行时完全看不出来。
5. **这一轮要删 / 合并 / 放宽什么?** 先删后加, 只增不减的红线集会在半年内变成装饰。

## 别抄清单(本仓特有, 抄过去就是错的)

|别抄|为什么|
|-|-|
|**31 条的门禁条数**|那是本仓失败史与吞吐的函数。条数本身就是照搬的入口。|
|阈值 `300 / 500 / 5 / 15 / 10`|本仓文件行数分布与目录规模算出来的; 换仓 median 都可能贴着它。|
|`ref/` `docs/archive/` 这类豁免|本仓的历史产物, 新仓没有。|
|五条 lane 的路径前缀|按新仓目录树重写; 前缀是目录前缀, 不是 glob。|
|ruff 的 10 条 ignore / biome 的 warning 集|那是本仓"存量欠账"的清单, 不是通用规则集。|
|`_` 前缀、中文命名、`impl/` 目录|本仓的目录约定。新仓可能是完全另一套(甚至相反)。|
|101 条探针的条数 / 101 这个数|= 规则数 × (违规组 + 控制组), 新仓自然算出自己的。|
|三份 settings 的 harness 名单|按新仓实际用的 runtime; 不支持 PreToolUse 的 runtime 硬塞拦截 hook 只会静默失效。|
|任何水位表 / 现状数字|见 `reference-params.md` 顶部: 那些数只在**标注的日期**下成立。|
